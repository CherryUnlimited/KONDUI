# KONDUI — Prototype

Prototype web de KONDUI, plateforme de réservation de chauffeurs à la demande (Cotonou, Bénin) : le chauffeur conduit le véhicule du client.

Trois espaces dans une seule page : **App client**, **App chauffeur**, **Administration**.

Prototype de démonstration : données simulées, temps accéléré, aucun paiement réel.
